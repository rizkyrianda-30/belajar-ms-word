Materi 1
Mengenal Word
Pengertian, bagian-bagian layar, dan cara menyimpan dokumen.
Definisi

Microsoft Word adalah aplikasi pengolah kata (word processor) untuk membuat, mengedit, memformat, menyimpan, dan mencetak dokumen teks seperti surat, laporan, makalah, dan proposal.

🖥️ Jelajah Jendela Word

Ketuk setiap bagian bernomor untuk mengetahui namanya.

Ketuk bagian di atasuntuk melihat nama dan fungsinya.

🎀 Jelajah Tab Ribbon

Ribbon berisi tab, dan setiap tab berisi beberapa grup perintah.

💾 Membuat & Menyimpan Dokumen

  1. Buka Word, pilih Blank document.
  2. Ketik isi dokumen.
  3. Tekan Ctrl + S, tentukan lokasi dan nama file.
  4. Format bawaan adalah .docx. Untuk PDF: File › Save As › PDF.
🧠 Ingat fungsi tabHome = huruf & paragraf · Insert = isipkan objek · Layout = lembar kertas · References = daftar isi · Review = periksa ejaan.

📐 Coba Sendiri: Preview Halaman

Orientasi

Margin

  1. Klik Insert › Page Number.
  2. Pilih posisi, misalnya Bottom of Page › Plain Number 2 (tengah bawah).
  3. Agar sampul tanpa nomor, centang Different First Page di tab Header & Footer.
  4. Klik Close Header and Footer untuk kembali menulis.

Header ada di bagian atas halaman, footer di bagian bawah. Cocok untuk judul laporan, nama sekolah, atau nomor halaman.

  • Insert › Header atau Footer
  • Atau klik dua kali area atas/bawah halaman

Tekan Ctrl + Enter (Insert › Page Break) agar bab baru selalu mulai di halaman baru, meskipun isi di atasnya berubah.

Membagi teks menjadi 2 atau 3 kolom, seperti pada brosur dan buletin.

🧠 Urutan kerjaAtur kertas & margin dulu → ketik → format → sisipkan nomor halaman.
Materi 4
Menyisipkan Objek
Tab Insert: tabel, gambar, bentuk, dan tautan. Ketuk untuk membuka langkahnya.
  1. Klik Insert › Table, tarik kotak grid untuk jumlah baris dan kolom.
  2. Isi sel. Tekan Tab untuk pindah ke sel berikutnya.
  3. Saat tabel dipilih muncul tab Table Design (gaya & garis tepi) dan Layout (khusus tabel).
  4. Di Layout: tambah baris/kolom, Merge Cells untuk menggabung sel, AutoFit untuk menyesuaikan lebar.
Contoh: jadwal, daftar nilai
  1. Insert › Pictures › This Device, pilih file gambar.
  2. Tarik sudut gambar untuk mengubah ukuran tanpa membuatnya gepeng.
  3. Atur posisi lewat Wrap Text (tab Picture Format).
  • In Line with Text: gambar diperlakukan seperti huruf (bawaan)
  • Square: teks mengelilingi gambar
  • Behind / In Front of Text: gambar di belakang/depan teks

Crop memotong bagian gambar yang tidak diperlukan.

  • Shapes: kotak, panah, bintang, dan lainnya. Warna lewat Shape Fill dan Shape Outline.
  • Text Box: kotak teks yang bebas diletakkan, cocok untuk poster dan sampul.
  1. Blok teks yang akan dijadikan tautan.
  2. Tekan Ctrl + K.
  3. Isi Address (alamat web) lalu klik OK.
  4. Tekan Ctrl + klik pada tautan untuk membukanya.

Menghapus: klik kanan › Remove Hyperlink.

🧠 IngatTable = data berbaris · Pictures = foto · Shapes = bentuk · Link = Ctrl+K.
Materi 5
Fitur Penting & Shortcut
Alat yang menghemat waktu saat mengerjakan tugas.
  • Ctrl+C salin · Ctrl+X potong · Ctrl+V tempel
  • Opsi tempel: Keep Text Only menempel teks polos tanpa format dari web
  • Ctrl+Z membatalkan (Undo), Ctrl+Y mengulang (Redo)
  • Ctrl+F mencari kata di seluruh dokumen
  • Ctrl+H mengganti kata: isi Find what dan Replace with
  • Replace All mengganti semua sekaligus. Periksa dulu sebelum menekannya.
  • Garis bergelombang merah menandai kata yang dianggap salah ejaan
  • Garis biru menandai saran tata bahasa atau gaya
  • Klik kanan kata bergaris untuk melihat saran perbaikan
  • Atur bahasa: Review › Language › Set Proofing Language (Indonesian)

Nama grup dan tampilan sedikit berbeda antarversi Word.

  1. Terapkan Heading 1 pada judul bab dan Heading 2 pada subbab (Home › Styles).
  2. Letakkan kursor di halaman daftar isi.
  3. Klik References › Table of Contents, pilih gaya.
  4. Jika isi berubah, klik Update Table.
Nomor halaman selalu akurat
  • Ctrl+S menyimpan. Lakukan sesering mungkin.
  • File › Save As untuk nama/lokasi/format baru: .docx atau PDF
  • Ctrl+P untuk cetak: lihat pratinjau, atur jumlah salinan dan rentang halaman (misalnya 1-3)

PDF menjaga tampilan tetap sama di perangkat apa pun.
